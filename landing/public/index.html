How it works

Three gestures. Zero friction. Built like a permanent upgrade to daily workflow.

01

Click

Press Ctrl+Shift+T (fully customizable). A calm dim overlay covers every monitor.

02

Drag

Draw a rectangle like Snipping Tool - live dimensions, Escape cancels, release commits at native resolution.

03

Paste

Accurate text is already on your clipboard. Optional preview to edit, re-copy, or re-process locally.

Premium where it matters

Maximum accuracy when you want it. Offline when you need it. Privacy by default.

Clip Desk + Ledger

Tray → Clip Desk. Search, pin, copy, then Export ledger.json. Import it back on this machine. Ledger files stay on disk you choose. A camera shutter plays when you snip (Windows; toggle in Settings).

Vision AI first

Connect your own xAI, OpenAI, Anthropic, or Google key. Grok vision by default for structure-aware transcription - code, tables, UI chrome, math.

Local OCR backup

RapidOCR (and optional Paddle / Easy / Tesseract) when offline or when you choose local-only mode. Lazy-loaded. No cloud required.

Privacy-first

Snips stay in memory unless you save the image from the preview. Keys live in your OS keyring when available. Local OCR never leaves the device. Vision AI sends the crop only to the provider you connect.

Multi-monitor ready

Correct high-DPI capture across displays. System tray resident with history, settings, and delayed snip for stubborn menus.

One-click connect

Tray → Connect AI → open key page → paste → Test connection. Human labels, not cryptic env vars.

FAQ

What is SnipText?

A desktop app that captures a screen region and places transcribed text on your clipboard. Hotkey, drag, release - done.

Is SnipText free?

Yes. The app is free and open source under MIT. Vision providers may bill for their own API usage if you add a key.

Do I need an API key?

No. Local OCR works offline. Add an xAI, OpenAI, Anthropic, or Google key in Settings for vision-model accuracy.

Where are my API keys stored?

Only on your machine (OS keyring when available). Keys are never bundled in the EXE and never required to use the app.

macOS / Linux?

Source runs on Windows, macOS, and Linux with Python 3.11+. The published portable zip is Windows only. Packaging scripts for other OS are in the repo.

What is Clip Desk?

The history window. Search, pin, copy, export a local JSON ledger, and import it back. Pins stay on this machine only.

What is The Ledger?

A local JSON file of your Clip Desk. Export and import stay on disk you choose. The ledger file is not uploaded.

How do I give credit if I fork?

Keep LICENSE and NOTICE, and credit Pitchfork-and-Torch in your README or About UI. Suggested line is in NOTICE.
